# Лабораторна №3. Основи регресійного моделювання

Ковальчук Ярослав, АтаВДвR-11.

- `report.qmd` — виконуваний R-документ, одночасно ноутбук і джерело звіту.
- `report.html` — зібраний звіт із кодом, результатами та бібліографією.
- `reports/presentation.qmd` і `reports/presentation.html` — джерело та готові дев’ять слайдів Quarto.
- `data/raw/energydata_complete.csv` — незмінений набір із лабораторної №2.
- `outputs/tables`, `outputs/figures`, `outputs/models` — розраховані результати, графіки та модель.
- `renv.lock` — точні версії R-пакетів; `outputs/sessionInfo.txt` — середовище виконання.

## Дані та протокол

Appliances Energy Prediction, Luis Candanedo, 2017. UCI, DOI https://doi.org/10.24432/C5VC8G, ліцензія CC BY 4.0. Отримано 16.11.2026 з https://github.com/LuisM78/Appliances-energy-prediction-data. Файл включено, повторне завантаження не потрібне. Ціль `Appliances` — енергія приладів у Wh за 10 хвилин. Один будинок, 19 735 початкових записів; після зсуву — 19 734 прогнозні пари.

Прогнозується наступний інтервал за попередніми завершеними сенсорними вимірюваннями та календарем. Перші близько 80% дат — навчання, решта — тест. Чотири часові блоки валідації; вибір за середнім RMSE до тесту. Порівняно константу, базову лінійну регресію та одну модифікацію. Попередній EDA всього набору обмежує незалежність тесту. Джерела, гіпотези, припущення доступності сенсорів і всі формули наведено у звіті.

## Відтворення

Перевірено з R 4.6.1 і Quarto 1.11.9. Потрібен офіційний Quarto CLI: https://quarto.org/docs/get-started/ . Відкрийте термінал у `lab03` (або в корені розпакованого архіву).

Для чистого середовища один раз запустіть у R:

```r
install.packages("renv", repos="https://cloud.r-project.org")
renv::activate()
renv::restore(prompt=FALSE)
```

На Windows, якщо середовище задає непідтримувану локаль, у PowerShell перед збиранням:

```powershell
$env:LC_ALL = "English_United States.utf8"
```

Побудова всього проєкту:

```sh
quarto render
```

Або послідовно:

```sh
quarto render report.qmd
quarto render reports/presentation.qmd
```

Звіт має бути зібраний перед слайдами: слайди читають підготовлені таблиці й графіки. Для інтерактивного виконання відкрийте `report.qmd` у VS Code з розширеннями R та Quarto. Окремий `.ipynb` не потрібний: умова дозволяє виконуваний `.qmd`.

Готові HTML відкриваються у браузері; слайди перемикаються стрілками. Шрифти й графіка вбудовані. Unbounded поширюється за SIL OFL (`reports/FONT-LICENSE.txt`).
