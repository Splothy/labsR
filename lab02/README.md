# Лабораторна робота №2 — енергоспоживання будинку

**Ковальчук Ярослав · АтаВДвR-11**

Розвідувальний аналіз даних на R. Досліджено розподіл споживання, добовий профіль, відмінності буднів і вихідних, зв’язки з погодою та освітленням і відмінності цих зв’язків у часових підгрупах. Регресійні моделі не навчаються.

## Що відкрити

## Джерело даних і ліцензія

**Appliances Energy Prediction**, Luis Candanedo (2017), [UCI](https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction), DOI [10.24432/C5VC8G](https://doi.org/10.24432/C5VC8G). Ліцензія **CC BY 4.0**: дозволено поширення та адаптацію із зазначенням авторства.

Оригінальний CSV: [репозиторій автора](https://raw.githubusercontent.com/LuisM78/Appliances-energy-prediction-data/master/energydata_complete.csv). Опис змінних збережено поряд із даними. Вихідний файл не змінювався.

Стаття: Candanedo, L. M., Feldheim, V., Deramaix, D. (2017). *Data driven prediction models of energy use of appliances in a low-energy house*. Energy and Buildings, 140, 81–97. DOI [10.1016/j.enbuild.2017.01.083](https://doi.org/10.1016/j.enbuild.2017.01.083).

Ціль `Appliances` — енергія побутових приладів у Wh за десятихвилинний інтервал. Потенційні фактори — температура, вологість, погода, освітлення та календарні ознаки. Спостереження стосуються одного будинку в Бельгії, 11.01–27.05.2016. У початковому файлі 19 735 рядків і 29 стовпців. `rv1` і `rv2` — випадкові змінні автора; вони не входять до змістовного аналізу.

## Запуск ноутбука

Потрібні R 4.6 або новіший, Python 3 з Jupyter Notebook та ядро R. Для перегляду збережених результатів виконувати ноутбук повторно не потрібно. Ноутбук також можна відкрити у VS Code з розширенням Jupyter, вибравши ядро R.

У терміналі:

```sh
python -m pip install notebook
```

У консолі R:

```r
install.packages(c("IRkernel", "readr", "dplyr", "tidyr", "ggplot2",
                   "lubridate", "svglite"), repos = "https://cloud.r-project.org")
IRkernel::installspec(user = TRUE)
```

Відкрити термінал у `lab02`:

```sh
jupyter notebook notebooks/EDA.ipynb
```

Вибрати ядро **R**, перезапустити його та виконати всі комірки зверху вниз. Ноутбук працює з поточною папкою `lab02` або `lab02/notebooks`. Пакети встановлюються лише за відсутності. На Windows перша комірка встановлює UTF-8 для правильного відображення української мови. Шрифт Unbounded додається з локальних файлів, якщо його немає в системі.

## Повторна побудова презентації

Потрібен [Quarto CLI](https://quarto.org/docs/get-started/). Після виконання ноутбука запустити з `lab02`:

```sh
Rscript -e "if (.Platform$OS.type == 'windows') Sys.setlocale('LC_ALL', 'English_United States.utf8'); source('scripts/build_presentation.R', encoding='UTF-8')"
quarto render reports/presentation.qmd
```

Скрипт читає підготовлені таблиці, а слайди використовують експортовані графіки. Щоб змінити структуру або текст презентації надовго, редагувати `scripts/build_presentation.R`; для одноразових правок можна редагувати `reports/presentation.qmd` та виконати лише другу команду. Готовий HTML містить графіки, шрифти та засоби навігації всередині одного файлу. Unbounded поширюється за SIL Open Font License; текст ліцензії — `reports/FONT-LICENSE.txt`.

## Важливі обмеження

Результати описують один будинок і частину року. Відомостей про присутність мешканців і роботу конкретних приладів немає. Погодні дані частково інтерпольовані. Часовий пояс у джерелі не задокументований: технічна шкала UTC використана для розбору надрукованих дат без конвертації часу. Сусідні інтервали залежні; кореляції не доводять причинність. Піки IQR позначені, але не видалені. Добові суми обчислено лише для 136 повних діб.
